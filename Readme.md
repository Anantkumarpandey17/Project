# 🚀 NemoNexus: Autonomous AI-Powered Agentic Workspace

NemoNexus is a hyper-futuristic, single-page autonomous AI agentic workspace designed to revolutionize how developers and students manage their technical research, code troubleshooting, and task scheduling. Built as a solo project in my very first semester of Computer Science, this platform puts an intelligent, centralized agent right into a unified neon-themed dashboard.

---

## 🌟 Core Features

- **Autonomous Research Hub (`RESEARCH` Tab):** Connects to the internet via Tavily AI and streams structured markdown documentation summaries parsed by advanced AI reasoning.
- **AI-Powered Command Console (`TERMINAL` Tab):** A custom, application-specific agent console executing intelligence logging commands like `status` and `scan` using natural language processing.
- **Task Orchestrator (`TASKS` Tab):** An automated scheduler that breaks down developer workflows and milestones into clear, actionable steps.
- **Cloud Telemetry Monitor:** Real-time simulated cluster telemetry dashboard displaying architecture CPU load and virtual memory usage under agentic workflows.

## 🚀 Local Installation & Setup

1. **Clone the repository:**
   ```bash
   git clone https://github.com
   cd NemoNexus
   ```

2. **Configure Environment Variables:**
   Create a `.env` file in the root directory and securely map your token:
   ```text
   TAVILY_API_KEY=your_free_tavily_api_key_here
   ```

3. **Install dependencies and fire up the engine:**
   ```bash
   npm install
   npm run dev
   ```
